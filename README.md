# Where-Am-I

Telegram-бот для отметок путешественников в одной группе. `/set Город, Страна` обновляет текущее место и добавляет историческую запись; `/list` показывает участников по городам, `/me` — вашу последнюю отметку. Все ответы на русском. Требования: [SPEC.md](SPEC.md).

## Требования

- Node.js **26.x**, npm, один процесс приложения.
- Telegram-бот и одна группа (предпочтительно приватная).
- Google Cloud project с включённым Google Sheets API, service account и одна закрытая Spreadsheet.
- HTTPS URL для webhook: Render Web Service либо туннель к локальному приложению.

## Настройка Telegram

1. Создайте бота в [BotFather](https://t.me/BotFather), сохраните токен в `TELEGRAM_BOT_TOKEN`.
2. Оставьте Privacy Mode включённым. Бота можно добавить в группу до или после деплоя. Права администратора не нужны.
3. Задайте числовой ID группы в `TELEGRAM_GROUP_ID` (обычно `-100…`). Узнать его можно по полю `message.chat.id` в Telegram `getUpdates`, пока webhook ещё не зарегистрирован: отправьте в группе `/help@ИмяВашегоБота`. Вызывайте API локально с токеном из переменной среды, не публикуйте URL с токеном.
4. После регистрации webhook используйте `/set@ИмяВашегоБота Берлин, Германия`, если Telegram не доставляет короткую команду при Privacy Mode. Команды другому боту игнорируются.

При переходе обычной группы в supergroup Telegram меняет её ID: обновите конфигурацию, перезапустите сервис и повторите регистрацию webhook. Автоматическая миграция группы не предусмотрена.

## Настройка Google Sheets

1. Создайте Google Cloud project, включите **Google Sheets API**.
2. Создайте service account и JSON-ключ. В `.env` или Render Environment перенесите `client_email` и `private_key`; не помещайте JSON-ключ в репозиторий.
3. Вручную создайте Google Spreadsheet. Предоставьте service account доступ **Editor**. Таблицу не публикуйте.
4. Скопируйте ID из `https://docs.google.com/spreadsheets/d/<ID>/edit` в `GOOGLE_SPREADSHEET_ID`.

На старте приложение создаёт отсутствующие `Users` и `LocationHistory` и их заголовки. Существующие данные и посторонние листы не удаляются; стандартный пустой «Лист1» можно удалить вручную до запуска. При несовместимых заголовках запуск завершается с ошибкой: сначала проверьте схему по SPEC.md. При пустом заголовке и наличии данных бот также останавливается, не перезаписывая их.

Telegram ID записываются строками, координаты — числами, время — ISO UTC. Строки записываются как текст, а не формулы. Сохранение текущего места и истории выполняется одним атомарным `spreadsheets.batchUpdate`. История содержит отдельную строку для каждого успешного `/set`, включая повтор того же города. Во время работы не редактируйте и не переставляйте строки вручную.

## Конфигурация

Скопируйте `.env.example` в `.env` и заполните значения. `.env` исключён из Git. Никогда не коммитьте JSON-ключи, токены или приватные ключи.

| Переменная | Назначение |
| --- | --- |
| `NODE_ENV` | `development` или `production`; по умолчанию `development` |
| `LOG_LEVEL` | `debug`, `info`, `warn`, `error`, `silent`; по умолчанию `info` |
| `PORT` | Порт HTTP; по умолчанию `3000`, на Render предоставляется платформой |
| `PUBLIC_BASE_URL` | Публичный HTTPS origin сервиса, без пути |
| `TELEGRAM_BOT_TOKEN` | Секретный токен BotFather |
| `TELEGRAM_GROUP_ID` | Строка с отрицательным ID единственной группы |
| `TELEGRAM_WEBHOOK_SECRET` | Случайный секрет: 1–256 символов `A-Z a-z 0-9 _ -` |
| `GOOGLE_SPREADSHEET_ID` | ID файла Spreadsheet |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | Email service account |
| `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` | PEM-ключ; поддерживаются настоящие переводы строк и буквальные `\n` |
| `NOMINATIM_USER_AGENT` | Название приложения, версия и **реальный email владельца** |
| `NOMINATIM_BASE_URL` | Необязательный HTTPS адрес совместимого сервиса; по умолчанию `https://nominatim.openstreetmap.org` |
| `RENDER_HEALTH_URL` | Полный URL `/health`; нужен только GitHub Actions, задаётся в repository Variables |

Пример в `.env.example` намеренно содержит заглушки. Контакт на `example.com` не проходит проверку конфигурации. В Render вводите значения без внешних кавычек. Все переменные приложения, включая Google, проверяются и при запуске setup-скрипта.

## Локальный запуск

```sh
npm ci
npm run test
npm run lint
npm run typecheck
npm run build
npm run dev
```

Сервер слушает `0.0.0.0:3000`. `GET /health` возвращает `{"status":"ok"}` без обращения к Google или Nominatim. До начала приёма запросов основной процесс проверяет Google Sheets и Telegram-токен.

Для работы Telegram направьте HTTPS-туннель на локальный порт 3000, задайте его URL в `PUBLIC_BASE_URL`, перезапустите приложение и выполните:

```sh
npm run webhook:set
```

Скрипт регистрирует webhook `/telegram/webhook` с секретом, `max_connections=1` и обновлениями `message`, `callback_query`, `my_chat_member`, затем описание бота и меню команд группы. Ошибка регистрации webhook останавливает setup. Недоступная группа или ошибка настройки меню создаёт только предупреждение и не мешает запуску. Бота можно добавить в указанную группу после деплоя: событие `my_chat_member` повторит настройку меню автоматически, без перезапуска. Текстовые команды работают независимо от успешности настройки меню. Скрипт не удаляет ожидающие обновления. При смене URL повторите регистрацию. Polling приложение не запускает.

Для запуска скомпилированной версии выполните `npm run start`; команда также подхватывает локальный `.env`, если он существует.

## Деплой на Render Free

1. Отправьте репозиторий в GitHub. Создайте **Web Service**, runtime Node, план Free, один инстанс.
2. Build Command: `npm ci --include=dev && npm run build`.
3. Start Command: `node dist/scripts/register-webhook.js && npm run start`.
4. Задайте `NODE_VERSION=26` в Environment, `NODE_ENV=production` и остальные переменные приложения. `PUBLIC_BASE_URL` — адрес созданного сервиса. Health Check Path: `/health`.
5. Дождитесь событий `webhook_setup_completed` и `app_ready`, проверьте `/health`. Webhook регистрируется автоматически на Render при каждом запуске. При отсутствии бота в группе предупреждения `telegram_commands_*_failed` допустимы; setup и запуск продолжаются.
6. Добавьте бота в целевую группу, если ещё не добавили. Проверьте `/set`, `/list` и `/me`. Перезапустите Render и убедитесь, что данные остались, а заголовки не продублировались.

Секреты задаются вручную; приложение ничего не хранит на локальном диске Render. При SIGTERM/SIGINT сервер завершает текущие запросы и закрывается.

### Keep-alive и CI

В GitHub Settings → Secrets and variables → Actions → **Variables** добавьте `RENDER_HEALTH_URL=https://<render-host>/health`. Workflow `Render keep-alive` запускает `curl` раз в 10 минут и вручную через Actions → Run workflow. Для scheduled workflows файл должен находиться в default branch, а Actions — быть разрешены.

Render Free может засыпать после 15 минут без входящих запросов. Ping уменьшает вероятность засыпания, но расписание GitHub может задерживаться и отключаться после длительной неактивности публичного репозитория. Проверьте текущие [ограничения Render](https://render.com/docs/free) и [правила расписаний GitHub](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule). Холодные старты и исчерпание бесплатных часов возможны; SLA отсутствует.

CI на push и PR запускает тесты, lint, typecheck и build на Node.js 26. Внешние API в тестах заменены моками, секреты не требуются.

В `package.json` закреплён override `minimatch` на исправленную ветку 11: это устраняет уязвимость транзитивной зависимости инструментов ESLint. При обновлении инструментов проверьте необходимость override через `npm audit` и повторите lint.

## Геокодирование и ограничения MVP

Публичный Nominatim используется только для добровольного `/set`: не более одного начала HTTP-запроса в секунду на процесс, тайм-аут 10 секунд, без автоматических повторов. `/list` и `/me` его не вызывают. Нужны идентифицирующий User-Agent с действительным контактом и атрибуция OSM: `webhook:set` размещает её в описании бота, чтобы подтверждение `/set` занимало одну строку. `/me` показывает только дату обновления в формате `ДД.ММ.ГГГГ` по времени Минска; в таблице сохраняется полное время UTC. Перед использованием ознакомьтесь с [политикой Nominatim](https://operations.osmfoundation.org/policies/nominatim/).

По SPEC.md кэша нет. Публичный сервис имеет ограниченную ёмкость; частые повторяющиеся запросы создают риск блокировки. Не используйте autocomplete, массовое или фоновое геокодирование. При росте нагрузки пересмотрите требования к кэшу или переключите `NOMINATIM_BASE_URL` на совместимого провайдера и перезапустите сервис. Не увеличивайте частоту запросов. Провайдер может потребовать другую реализацию `PlaceResolver`.

Бот принимает населённые пункты с валидной страной и координатами, отбрасывает улицы, отели и инфраструктуру. Несколько подходящих OSM-объектов требуют уточнения страны/региона новой командой. Автоматическое исправление опечаток не гарантируется; разные OSM-объекты не объединяются по похожему названию. Координаты показывают центр заявленного населённого пункта, а не положение телефона.

Пагинация содержит до 20 участников и укладывается в лимит Telegram. Любой участник разрешённой группы может перелистывать общее сообщение; каждый переход перечитывает актуальные данные. При необходимости длинные подписи сокращаются только при отображении. Если данные изменились, устаревший номер страницы ограничивается последней существующей страницей.

В MVP нет удаления отметок, TTL, обработки выхода участников, просмотра истории в Telegram, карт, нескольких групп и дедупликации webhook. Повторная доставка update может добавить лишнюю строку истории. При неопределённом результате записи автоматический повтор не выполняется; проверяйте таблицу перед ручным повтором команды. История доступна только владельцу Spreadsheet. Публичная группа делает опубликованные в ней списки публичными.

## Логирование

Приложение и `webhook:set` пишут JSON-события в stdout; в Render они видны в Logs. В каждой записи есть UTC-время, уровень и `event`. Уровень задаётся `LOG_LEVEL=info`; для диагностики установите `debug` и перезапустите процесс. `silent` полностью отключает логи.

- `info`: запуск и готовность приложения, инициализация листов, успешная запись отметки, ответы на команды, перелистывание списка, регистрация webhook, завершение процесса.
- `warn`: отклонённый ввод, неоднозначное место, запрещённый чат, неправильный секрет webhook и некорректная callback-кнопка.
- `error`: сбои Google Sheets, Nominatim и Telegram, ошибки запуска, HTTP-обработки и завершения процесса.
- `debug`: начало и длительность операций, чтение листов, результаты поиска (только количество), получение и завершение обработки updates и webhook. Запросы `/health` не засоряют логи.

Для ошибок записываются тип, известный код, HTTP-статус и этап операции; для команд — Telegram `update_id` (только для диагностики, без хранения и дедупликации). `location_saved` означает подтверждённую запись в таблицу, даже если последующая отправка ответа Telegram завершилась ошибкой. При ошибке конфигурации перечисляются только имена неверных переменных.

Токены, секретные заголовки, приватные ключи, тела запросов и ответов API, произвольные сообщения и stack trace SDK-ошибок, текст `/set`, города, координаты, имена, username и Telegram user ID не логируются. Исправление временного сбоя не приводит к автоматическому повтору записи.

## Проверка после настройки

1. `/help` и `/start` возвращают ровно две строки из SPEC.md.
2. `/set Берлин, Германия` создаёт строку `Users` и строку `LocationHistory`; повтор добавляет только новую историю и обновляет текущую запись.
3. `/list` показывает пользователя один раз, с кликабельным именем; `/me` показывает последнюю отметку.
4. Пустой ввод, URL, адрес, координаты, несуществующее или неоднозначное место не записываются.
5. В личном чате и другой группе данные не выдаются. Анонимный администратор не создаёт отметку.
6. При нескольких страницах другой участник группы может нажимать кнопки; история не меняется.
7. После рестарта Render всё сохраняется. Выход человека из группы не меняет данные.
8. Ручной запуск keep-alive получает HTTP 200; webhook без секретного заголовка получает 403.

Если бот молчит, проверьте ID группы, адресацию команды и регистрацию webhook. Если `/health` недоступен, проверьте Render Logs: конфигурацию, доступ service account и заголовки листов. SDK-ошибки намеренно не печатаются целиком, чтобы не раскрывать секреты. При временной ошибке сохранения не считайте команду успешной — проверьте Google Sheets.
